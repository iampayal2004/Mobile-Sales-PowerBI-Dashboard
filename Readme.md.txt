📊 Mobile Sales Dashboard | Power BI

Project Overview

An interactive Mobile Sales Dashboard created using Microsoft Power BI to analyze sales performance and identify business insights.

This project is part of my Power BI learning journey through the Skill Course by Satish Dhawale Sir.

Tools Used

- Microsoft Power BI
- Data Visualization
- Data Analysis

Dashboard Features

- Total Sales, Total Quantity, Transactions, and Average Sales KPI cards
- Sales by City map visualization
- Monthly quantity trends
- Customer ratings analysis
- Transactions by payment method
- Sales by mobile model
- Interactive filters for mobile model, payment method, brand, day, and month

Project Objective

To analyze mobile sales data and present meaningful insights through an interactive dashboard.
